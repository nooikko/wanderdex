# Security Policy

## Reporting a vulnerability

**Please do not open a public issue for security problems.**

Report it privately through GitHub instead:
[**Report a vulnerability**](https://github.com/nooikko/wanderdex/security/advisories/new)
(also on the repository's **Security** tab).

Include what you found, how to reproduce it, and the Wanderdex version and OS you saw it on.
The report stays private between you and the maintainers until a fix is ready.

## Supported versions

Fixes go into the latest release. Please check that the problem still happens there before reporting.
